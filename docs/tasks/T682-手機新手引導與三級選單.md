# T682 手機新手引導與三級選單

**Claim**　GPT (Codex)，2026-11-21，分支 `gpt/town-mobile-t682`，起點 `e8e0471`（v11.256）。

**業主原話**　「手機新手提示被遮住」「這個開一張 UI 卡 手機的優化一下 UI 吧 合理排列， 一二三級菜單重新設計 激進的以先進的審美做完吧」。

## 玩家現在遇到的問題

390 × 844 的新城畫面裡，港區按鈕蓋住第一句鋪路教學。頂端的系統按鈕換了好幾排，底端另有分類、工具和縮放。玩家還沒選到支路，就得先找提示、再找工具。

## 交付

- 手機常駐列只保留一眼要看的狀態與回到操作選單的入口。第二層按玩家目的分組，第三層選工具或執行操作。選完可以直接操作地圖。港區、資源、視圖、存檔及既有分類與工具仍可達。
- 教學有自己的可讀區域，關閉鍵可點。選單支援返回、關閉與鍵盤。跨過手機與桌面分界時恢復對應版面。
- 限主線遊戲 DOM、CSS、控制路由及其驗證，版本文件、服務工作者版本、逃生閥登記與本卡證據。沿用遊戲既有控制項及建造規則，保留桌面操作與玩家存檔。

## 凍結驗收

1. 在 320、360、390、412 像素寬的直向和 844 × 390 橫向，真實瀏覽器開新城。讀取第一句教學、點擊關閉，確認文字與關閉鍵的實際命中位置。不讓港區、小地圖、常駐列或展開選單吃掉教學點擊。
2. 實走一級入口 → 二級分類 → 三級支路 → 回圖鋪路；核對工具選取和落地。工具長清單最後一項可達。驗證港區開關、存檔、檢視／系統操作與原處理器相通，保留條件式工具／控制。
3. 小尺寸和橫向可捲動，無頁面水平溢位；主要選單及教學關閉目標至少 44 × 44 CSS px。支援返回、Escape、外點關閉、旋轉以及焦點回復。教學與選單的版位各自保留空間。
4. 1024／1440 寬桌面保留現有 HUD 和工具列。網址 `?noT682=1` 及載入前 `window.__noT682=true` 各自可恢復舊手機介面。沿用 T679、T680 回退機制。
5. 新城與舊檔在隔離站點、預設槽 3 驗證；提供真實 Chrome 手機尺寸與桌面畫面。驗證腳本對故障輸入能報錯。完整 verify、六哨兵、官方 gate 及發布頁結果分別記錄。

手機驗收沿用業主指定的電腦瀏覽器方式。本卡衡量可讀性、可達性與遊戲操作，不宣稱實機效能。

## 實作與畫面

常駐列顯示財政、人口、日期、速度與存檔。底座可直接切分類、縮放、檢視或拆除。「建設 → 道路 → 支路」保留原建造價與滑動鋪路；長清單可以展開。「城市 → 市政與營運 → 港區營運」開啟原港區面板。「地圖」提供旋轉、圖層和小地圖。展開面板從教學下緣到常駐底座之間取可用高度。
